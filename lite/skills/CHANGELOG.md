# CHANGELOG

## v2.5.0 (2026-05-19)

### 重大升级：多平台热搜 + 资金深度分析 + 情绪指标 + 自选股管理 + 个股画像 + HTML报告

**V2.1 高优先级（已完成）**

#### 1. 数据源与热搜能力升级
- 🆕 多平台热搜覆盖：微博/东方财富股吧/雪球/抖音/知乎
- 🆕 按平台筛选：`--platforms weibo,xueqiu`
- 🆕 热搜情绪倾向分析（正面/负面/中性，基于关键词分词）
- 🆕 热搜关联事件提取（AI芯片/新能源/政策利好/业绩公告等）
- 🆕 黑名单过滤（过滤泛关键词如单独的"A股"）
- 🆕 模糊匹配 + 精确匹配组合
- 🆕 多平台数据源状态显示
- 🆕 代理池支持：`--proxy http://127.0.0.1:7890`

#### 2. 资金与行情分析深化
- 🆕 北向资金十大成交股
- 🆕 北向资金行业流向分布
- 🆕 北向资金持仓变动 Top10
- 🆕 主力/游资/散户资金流向统计
- 🆕 大单/中单/小单成交占比
- 🆕 龙虎榜集成（涨停板自动标注上榜股票）
- 🆕 恐慌贪婪指数（多维度：涨跌比/涨跌停/北向/大盘）
- 🆕 两融余额变化
- 🆕 涨跌停家数历史分位

#### 3. 自选股功能体验优化
- 🆕 自选股批量导入导出（TXT/CSV）
- 🆕 自选股分组管理（短线/中线/行业分组）
- 🆕 自选股实时预警（涨跌幅/换手率/热搜/资金异动）
- 🆕 自选股每日简报生成

#### 4. 稳定性与错误处理优化
- 🆕 AKShare 适配层（版本兼容 + 降级机制）
- 🆕 代理池支持（解决微博限流）
- 🆕 友好错误提示（限流/超时/版本过低）
- 🆕 代码重构为模块化结构

**V2.2 中优先级（已完成）**

#### 1. 板块轮动与行业分析升级
- 🆕 多周期轮动对比（7/14/30天）
- 🆕 板块强度评分（涨幅+资金+热度综合，满分100）
- 🆕 板块内部分化分析（龙头/跟风/掉队）
- 🆕 行业基本面关联（PE/PB）
- 🆕 概念板块细分（AI→AI芯片/大模型/算力租赁/AI应用等）

#### 2. 个股分析能力增强
- 🆕 个股多维画像（`--profile`）
- 🆕 基本面（PE/PB/总市值/流通市值）
- 🆕 技术面（MACD/KDJ/RSI/MA5/10/20/60）
- 🆕 资金面（主力/超大单/大单/中单/小单）
- 🆕 消息面（最新公告/新闻）
- 🆕 异常检测（成交量/换手率/振幅/连涨连跌）
- 🆕 热搜-涨跌关联分析

#### 3. 输出与可视化升级
- 🆕 交互式 HTML 报告（Chart.js 图表，`--html`）
- 🆕 本地数据归档（`--archive`，按日期）
- 🆕 Webhook 自动推送（钉钉/企微/飞书，`--push`）
- 🆕 定时任务管理（`--schedule`/`--webhook`）

#### 4. 板块深度分析
- 🆕 板块内部分析（`--sector-detail`）
- 🆕 概念细分查询（`--subdivisions`）

### 架构变更
```
scripts/
├── analyzer.py              # 主入口（V2.4）
├── sources/                 # 5个数据源
│   ├── weibo.py             # 微博热搜
│   ├── eastmoney_guba.py    # 东方财富股吧
│   ├── xueqiu.py            # 雪球热帖/热股
│   ├── douyin.py            # 抖音热搜
│   ├── zhihu.py             # 知乎热榜
│   └── multi_platform.py    # 聚合 + 关键词筛选 + 黑名单
├── analysis/                # 6个分析模块
│   ├── hotsearch.py         # 情绪/事件/趋势/历史回溯
│   ├── capital.py           # 北向增强/主力拆分/龙虎榜
│   ├── sentiment.py         # 恐慌贪婪/两融/涨跌停分位
│   ├── watchlist.py         # 分组/预警/导入导出
│   ├── sector.py            # 板块轮动/强度评分/内部分化/概念细分
│   └── stock_profile.py     # 个股画像/技术指标/异常检测
├── output/                  # 输出模块
│   ├── html_report.py       # 交互式HTML报告（Chart.js）
│   └── automation.py        # 定时任务/Webhook推送/归档
├── utils/                   # 工具模块
│   ├── common.py            # 通用工具函数
│   └── akshare_adapter.py   # AKShare 适配层
└── demo.py                  # 旧版演示（保留）
```
